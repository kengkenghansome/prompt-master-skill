# Text Prompt Framework

## Core idea

Text prompts should be written like a professional task brief.

A strong text prompt tells the AI:

- what role to play
- what background to use
- what task to complete
- who the audience is
- what content to include
- what structure to follow
- what tone to use
- what restrictions to obey
- what quality standard to meet

## Core formula

角色身份 + 背景信息 + 任务目标 + 目标受众 + 内容范围 + 输出结构 + 风格语气 + 限制条件 + 质量标准

## Required structure

### 1. 角色身份

Define the professional role.

Examples:

- senior industry analyst
- business consultant
- copywriter
- product manager
- software architect
- UI designer
- financial analyst
- legal assistant
- teacher
- translator

### 2. 背景信息

Provide context.

Include:

- existing material
- business background
- target scenario
- known facts
- constraints
- data source
- user preference

### 3. 任务目标

Define what needs to be done.

Examples:

- write a report
- summarize content
- translate directly
- rewrite for management
- generate PPT outline
- create a marketing copy
- analyze a problem
- draft an email

### 4. 目标受众

Define who will read the output.

Examples:

- company management
- ordinary consumers
- investors
- clients
- beginners
- social media users
- internal team

### 5. 内容要求

Define what must be included.

Examples:

- key facts
- background
- comparison
- conclusion
- recommendation
- risks
- data
- examples

### 6. 输出结构

Define the format.

Examples:

- title + conclusion + body + summary
- table
- bullet points
- bilingual version
- email format
- PPT page structure
- executive summary

### 7. 风格语气

Define the language style.

Examples:

- formal
- business-like
- concise
- sincere
- deep
- neutral
- management-report style
- Xiaohongshu style
- technical documentation style

### 8. 限制条件

Define what not to do.

Examples:

- do not fabricate data
- do not over-explain
- do not use exaggerated words
- do not use markdown table
- keep within 300 words
- direct translation only
- avoid casual tone

### 9. 质量标准

Define what good output looks like.

Examples:

- clear logic
- directly usable
- suitable for target audience
- professional
- structured
- concise
- accurate
- consistent with source material

## Final text prompt template

请你以【角色身份】的身份，基于以下背景信息，完成【具体任务】。

背景信息：
【输入背景】

任务目标：
【希望文本达到什么效果】

目标受众：
【写给谁看】

内容要求：
1. 必须包含【必要信息】
2. 重点突出【重点内容】
3. 简化【复杂内容】
4. 避免【不适合内容】

输出结构：
请按照以下格式输出：
1. 标题
2. 核心结论
3. 正文内容
4. 重点摘要
5. 后续建议 / 可选补充

风格语气：
【正式 / 商务 / 口语 / 深刻 / 简洁 / 管理层汇报 / 小红书风格 / 技术文档风格】

限制条件：
- 字数控制在【XX】字以内
- 不要编造数据
- 不要过度解释
- 不要使用【XX】表达
- 语言要适合【具体场景】

质量标准：
- 逻辑清晰
- 重点突出
- 可直接复制使用
- 符合目标受众阅读习惯
